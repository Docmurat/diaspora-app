# Минги-Тау

Закрытое приложение-сообщество для карачаевцев и балкарцев. Цель — сплочение
народа: люди находят друг друга, помогают друг другу и делятся знаниями.
Вход только по приглашению. Проект некоммерческий.

Основатель проекта — Мурат Курджиев.

## Основные функции

1. **Каталог людей** — при регистрации участники заполняют анкету (кто, чем
   занимается, чем может быть полезен). Поиск по профессии и городу, личные
   сообщения.
2. **Стена помощи** — лента тем по категориям: «нужна помощь» / «могу
   помочь». Уведомления получают специалисты выбранной категории.
3. **Статьи** — участники пишут материалы о традициях, фамилиях,
   профессиональные советы.
4. **Полезные ресурсы** — подборка сайтов и приложений, связанных с народом.
5. **Афиша** — мероприятия, посвящённые народу.

## Технологии

- **Expo (React Native)** — один код для Web, Android и iOS
- **Expo Router** — навигация
- **Supabase** — база данных, авторизация, хранилище файлов, Edge Functions
- **TypeScript**

## Запуск проекта

1. Установить зависимости:

   ```bash
   npm install
   ```

2. Запустить в режиме разработки:

   ```bash
   npx expo start
   ```

   Далее: `w` — открыть веб-версию в браузере, или отсканировать QR-код
   приложением Expo Go на телефоне.

## Секреты и пароли

Пароли, ключи и любые секреты **не хранятся в этом репозитории** — он
публичный. Ключи почтового ящика и прочие секреты живут в настройках
Supabase (Edge Functions → Secrets).

## Статус

Реализовано: регистрация с анкетой, подтверждением почты по коду и
модерацией; система приглашений; личные чаты; профили; поиск; избранное;
жалобы и модерация. Оформление переведено на дизайн-систему «Минги-Тау».

В планах: перестройка навигации по утверждённой карте, стена помощи,
статьи, каталог ресурсов, афиша, уведомления, PWA.

Подробности разработки — в файле `CLAUDE.md`.

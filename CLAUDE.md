## О проекте

Закрытое приложение-сообщество для карачаевцев и балкарцев. Доступ только представителям народа (регистрация по приглашениям + модерация). Цель — сплочение нации.

Пять функций (по плану):

1. **Каталог людей** — анкеты (кто, профессия, город, чем полезен), поиск с фильтрами («Стоматолог Москва»), личные сообщения. ЧАСТИЧНО ГОТОВО.
2. **Стена помощи** — форум по категориям профессий, ветки «нужна помощь» / «могу помочь», уведомления специалистам категории, закрытие решённых веток. НЕ НАЧАТО.
3. **Статьи** — публикации участников (принцип Яндекс Дзена). НЕ НАЧАТО.
4. **Каталог ресурсов** — полезные сайты и приложения народа. НЕ НАЧАТО.
5. **Афиша** — мероприятия народа. НЕ НАЧАТО.

## Технологии

- Expo SDK 54 (React Native + TypeScript), Expo Router — один код на Web / Android / iOS
- Supabase — база данных, авторизация, хранилище (ключ в lib/supabase.ts — публичный, это нормально)
- Репозиторий: https://github.com/Docmurat/diaspora-app (ветка main)
- Стратегия запуска: веб-приложение для телефонов и планшетов + PWA. На широких экранах (десктоп) приложение показывается колонкой до 768px по центру («планшетная рамка» в app/\_layout.tsx). Полноценная десктопная вёрстка — далёкое будущее. Магазины приложений — позже.

## Правила ведения работы (для Claude)

1. Работать пошагово, ждать подтверждения пользователя после каждого шага.
2. После завершения каждой вехи — предложить пользователю обновить этот файл (Claude готовит новую версию, пользователь коммитит: Commit → Sync).

4. Claude всегда даёт готовые файлы для вставки (не просит пользователя писать код руками).
5. **Именование одиночных файлов:** имя файла = путь в проекте, разделитель папок — двойное подчёркивание `__`. Пример: `app/(tabs)/index.tsx` → `app__(tabs)__index.tsx`. Пользователь сам открывает нужный файл и вставляет код (копипаст) — подробные инструкции по размещению не нужны.
6. Если файла ещё нет в проекте — Claude явно помечает: **НОВЫЙ ФАЙЛ** (пользователь сначала создаёт его по указанному пути).
7. Если файлов больше двух — передавать архивом (.zip) с готовой структурой папок: распаковать в корень проекта с заменой.
8. Перед крупными изменениями проверять код компилятором (tsc) на своей стороне.

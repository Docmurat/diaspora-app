**Минги-Тау** — закрытое мобильное/веб-приложение (сообщество) для карачаевцев
и балкарцев по всему миру. Вход только по приглашению. Подпись бренда:
«Карачаево-Балкарское сообщество».

- Отправка на GitHub: Source Control → Commit → Sync Changes.

## ДИЗАЙН-СИСТЕМА (утверждена, основополагающая для ВСЕХ экранов)

Стиль: современный «iOS / liquid glass» — светлый, воздушный, пастельный.
Отсылки к культуре: логотип-гора (Эльбрус/Минги-Тау) и знак **текмет**
(круг + ромб + точка) — фирменный знак и орнаментальный разделитель.

**ВАЖНО (решение Вехи 5):** живой цветной фон с боке — ТОЛЬКО на welcome.
Экраны с формами и рабочие экраны — на белом фоне `#FFFFFF`, фирменные
элементы (Philosopher, текмет, зелёные кнопки, скруглённые поля)
сохраняются.

**Иконки (Веха 6):** иконка приложения и сайта — знак текмет во всю
ширину на прозрачном фоне, зелёный `#69B78D`. Исключения по техтребованиям:
apple-touch-icon и maskable — на белой подложке; Android-иконки — знак в
безопасной зоне (система режет по кругу). Файлы: `assets/images/`
(icon, favicon, android-\*) и `public/icons/` (PWA).

### Общий файл дизайн-системы — `components/mingi.tsx`

Все экраны берут элементы отсюда, НЕ копируют код:

- `Glass` — стеклянная карточка (слои с `pointerEvents="none"`, контент
  поднят через zIndex — иначе в вебе текст прячется под стеклом).
- `Blob`, `useDrift` — пятна боке и их анимация.
- `Tekmet` — текмет-разделитель.
- `MingiBackground` — живой фон (только welcome-подобные экраны;
  уникальный `idPrefix`).
- Побочный эффект при импорте: глобальное отключение чёрной браузерной
  рамки фокуса в вебе (`*:focus { outline: none }`).

`components/AvatarCrop.tsx` — окно кадрирования фото профиля:
перетаскивание, масштаб − / +, круг, обрезка 512×512 JPEG. Экспортирует
`prepareAvatarSource()` — сразу уменьшает выбранное фото (≤ 1600 px),
чтобы не держать тяжёлый оригинал в памяти.

### Шрифты

- **Philosopher** (OFL): `Philosopher_700Bold` — заголовки;
  `Philosopher_400Regular` — подписи. `useFonts` внутри экрана,
  до загрузки — пустой фон.
- Системный шрифт — кнопки и служебный текст (fontWeight 600 на кнопках).

### Шаблон экрана с формой

Заголовок Philosopher 34 → подпись капсом → текмет → поля →
primary-кнопка → ссылки. Радиусы: кнопки 18, поля 16. Обязательные поля —
`*` в плейсхолдере + строка «Поля со звёздочкой (\*) обязательны»;
кнопки неактивны (opacity 0.7), пока обязательные поля не заполнены.

### Логотип и веб

- `assets/logo-mingi.png` — гора (бренд-архив), welcome использует
  `assets/Logo-start.png`.
- `app/+html.tsx` — заголовок «Минги-Тау», theme-color, манифест PWA,

- `public/manifest.json` — манифест PWA. Кнопка установки появится

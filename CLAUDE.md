## Что это за проект

**Минги-Тау** — закрытое мобильное/веб-приложение (сообщество) для карачаевцев
и балкарцев по всему миру. Вход только по приглашению. Подпись бренда:
«Карачаево-Балкарское сообщество».

- Строго пошагово, одно действие за раз, без жаргона.
- Окружение: Windows, PowerShell, VS Code, папка проекта `C:\dev\Diaspora`.
- Отправка на GitHub: Source Control → Commit → Sync Changes.
- Всегда давать готовые файлы (не просить писать код руками).

  (пример: `app__(tabs)__index.tsx`), всегда писать куда положить и как

## ДИЗАЙН-СИСТЕМА (утверждена, основополагающая для ВСЕХ экранов)

Стиль: современный «iOS / liquid glass» — светлый, воздушный, пастельный.
Отсылки к культуре: логотип-гора (Эльбрус/Минги-Тау) и знак **текмет**
(круг + ромб + точка) как деликатный орнаментальный разделитель.

**ВАЖНО (решение Вехи 5):** живой цветной фон с боке — ТОЛЬКО на welcome
(визитная карточка). Экраны с формами (login, invite, register,
request-invite и все будущие рабочие экраны) — на спокойном белом фоне
`#FFFFFF`, фирменные элементы (Philosopher, текмет, зелёные кнопки,
скруглённые поля) сохраняются.

### Общий файл дизайн-системы — `components/mingi.tsx`

Все экраны берут элементы отсюда, НЕ копируют код:

- `Glass` — стеклянная карточка (актуальная версия: слои с
  `pointerEvents="none"`, контент поднят через zIndex — иначе в вебе текст
  прячется под стеклом).
- `Blob`, `useDrift` — пятна боке и их анимация.
- `Tekmet` — текмет-разделитель.
- `MingiBackground` — живой фон (используется только на welcome-подобных
  экранах; требует уникальный `idPrefix`).
- Побочный эффект при импорте: глобальное отключение чёрной браузерной
  рамки фокуса в вебе (`*:focus { outline: none }`). Достаточно, чтобы
  экран импортировал что-либо из mingi.tsx.

`components/AvatarCrop.tsx` — модальное окно кадрирования фото профиля:
перетаскивание, масштаб − / +, круглая рамка, обрезка в квадрат 512×512
JPEG. Экспортирует `prepareAvatarSource()` — сразу после выбора фото
уменьшает его (длинная сторона ≤ 1600 px), чтобы не держать тяжёлый
оригинал в памяти.

- Заголовки / брендовый текст: `#3F6B5B`
- Вторичный текст (подписи капсом, letterSpacing 2.5): `#719686`
- Текст на стекле / выпадающие подсказки: `#4E7364`
- Кнопка primary: заливка `rgba(105,183,141,0.92)`, текст `#FFFFFF`,
  тень `#69B78D` (opacity 0.45, radius 14)
- Кнопка secondary: белая/стекло, абрис, текст `#3F6B5B`
- Поля ввода: белые `rgba(255,255,255,0.95)`, радиус 16, абрис
  `rgba(93,140,120,0.45)` толщиной `0.75`, плейсхолдер `#8FA79A`,
  текст `#2F4A3C`
- Служебный текст: `#7E988B`, ссылки: `#96AC9E` (подчёркнутые)
- Текст ошибок: `#C05B4D`
- Цвета боке: `#A8D8C0`, `#C2E3CF`, `#DFEFE3`, `#B7DEC8`, `#CDE8D6`

### Шрифты

- **Philosopher** (Google Fonts, OFL): `Philosopher_700Bold` — заголовки;
  `Philosopher_400Regular` — подписи. Подключение через `useFonts` внутри
  экрана, до загрузки — пустой фон.
- Системный шрифт — кнопки, служебный текст (fontWeight 600 на кнопках).

### Шаблон экрана с формой

Заголовок Philosopher 34 → подпись капсом (напр. «МИНГИ·ТАУ» или
«ШАГ 1 ИЗ 2») → текмет → поля → primary-кнопка → ссылки. Радиусы:
кнопки 18, поля 16. Обязательные поля помечаются `*` в плейсхолдере +
строка «Поля со звёздочкой (\*) обязательны» под текметом; кнопки
«Далее»/«Готово» неактивны (opacity 0.7), пока обязательные поля
не заполнены.

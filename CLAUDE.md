## Что это за проект

**Минги-Тау** — закрытое мобильное/веб-приложение (сообщество) для карачаевцев
и балкарцев по всему миру. Вход только по приглашению. Подпись бренда:
«Карачаево-Балкарское сообщество».

Владелец проекта — Мурат, не программист. Правила работы с ним:

- Строго пошагово, одно действие за раз, без жаргона.
- Окружение: Windows, PowerShell, VS Code, папка проекта `C:\dev\Diaspora`.
- Отправка на GitHub: Source Control → Commit → Sync Changes.
- Всегда давать готовые файлы (не просить писать код руками).
- Одиночные файлы называть по пути с `__` вместо `/`
  (пример: `app__(tabs)__index.tsx`), всегда писать куда положить и как
  переименовать. Больше двух файлов — zip-архив со структурой папок.
- После каждой вехи обновлять CLAUDE.md. После трёх вех в одном чате —
  напомнить открыть новый чат и подготовить стартовый текст.

- Expo / React Native + expo-router (TypeScript), веб-версия работает.
- Supabase: авторизация + база (таблица `users` и другие).
- GitHub: https://github.com/Docmurat/diaspora-app
- Установленные пакеты сверх базовых: `react-native-svg`, `expo-blur`,

## ДИЗАЙН-СИСТЕМА (утверждена, основополагающая для ВСЕХ экранов)

Стиль: современный «iOS / liquid glass» — светлый, воздушный, пастельный,
со стеклянными элементами и живым фоном. Отсылки к культуре: логотип-гора
(Эльбрус/Минги-Тау) и знак **текмет** (круг + ромб + точка) как деликатный
орнаментальный разделитель.

### Палитра

- Фон приложения: `#F4FAF4`
- Заголовки / основной брендовый текст: `#3F6B5B`
- Вторичный текст (подписи капсом, letterSpacing 2.5): `#719686`
- Текст на стекле (чипсы и т.п.): `#4E7364`
- Кнопка primary («Войти»): заливка `rgba(105,183,141,0.92)`, текст `#FFFFFF`,
  тень `#69B78D` (opacity 0.45, radius 14)
- Кнопка secondary: стекло `rgba(255,255,255,0.5)`, текст `#3F6B5B`
- Стеклянные поверхности: `rgba(255,255,255,0.5–0.55)` + BlurView intensity 22
- Тонкий абрис стеклянных элементов: `rgba(93,140,120,0.45)`, толщина `0.75`
- Служебный текст: `#7E988B`, ссылки: `#96AC9E` (подчёркнутые)
- Цвета боке: `#A8D8C0`, `#C2E3CF`, `#DFEFE3`, `#B7DEC8`, `#CDE8D6`

### Шрифты

- **Philosopher** (Google Fonts, лицензия OFL — свободная):
  `Philosopher_700Bold` — заголовки и брендовые надписи;
  `Philosopher_400Regular` — подписи и чипсы.
- Системный шрифт — кнопки, служебный текст, ссылки (fontWeight 600 на кнопках).
- Подключение: `useFonts` из `@expo-google-fonts/philosopher` внутри экрана,
  пока не загрузился — рендерить пустой фон (без мигания).

### Фирменные приёмы

- **Стекло (Glass)**: обёртка View (радиус, абрис, overflow hidden) →
  BlurView absoluteFill → цветная плёнка absoluteFill → контент.
  Так цвет не выцветает в вебе. Компонент `Glass` есть в `app/welcome.tsx`.
- **Дышащее боке**: 5 крупных (680–840) радиальных пятен, летают по всему
  экрану по несовпадающим периодам (7.2–14 сек, Lissajous) — хаотично и плавно.
- **Текмет-разделитель**: SVG (линия — круг с ромбом и точкой — линия),
  цвета `#CBE2D3` / `#9FC5AF`.
- Радиусы: кнопки 18, чипсы 999 (пилюли). Кнопки primary/secondary одинаковой
  высоты (paddingVertical 16).

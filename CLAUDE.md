## О проекте

Закрытое приложение-сообщество для карачаевцев и балкарцев. Доступ только представителям народа (регистрация по приглашениям + модерация). Цель — сплочение нации.

Пять функций (по плану):

1. **Каталог людей** — анкеты (кто, профессия, город, чем полезен), поиск с фильтрами («Стоматолог Москва»), личные сообщения. ЧАСТИЧНО ГОТОВО.
2. **Стена помощи** — форум по категориям профессий, ветки «нужна помощь» / «могу помочь», уведомления специалистам категории, закрытие решённых веток. НЕ НАЧАТО.
3. **Статьи** — публикации участников (принцип Яндекс Дзена). НЕ НАЧАТО.
4. **Каталог ресурсов** — полезные сайты и приложения народа. НЕ НАЧАТО.
5. **Афиша** — мероприятия народа. НЕ НАЧАТО.

## Технологии

- Expo SDK 54 (React Native + TypeScript), Expo Router — один код на Web / Android / iOS
- Supabase — база данных, авторизация, хранилище (ключ в lib/supabase.ts — публичный, это нормально)
- Репозиторий: https://github.com/Docmurat/diaspora-app (ветка main)
- Стратегия запуска: сначала веб + PWA, магазины приложений позже

## Пользователь (владелец проекта)

- Не программист. Формат работы: строго «степ бай степ» — Claude говорит, пользователь делает. Одно действие за раз, без жаргона, команды для PowerShell (Windows), путь проекта C:\dev\Diaspora.
- Работает в VS Code. Git настроен: изменения отправляются через Source Control → Commit → Sync Changes.
- Дизайн: текущий сохраняем, улучшаем постепенно и понемногу. Фирменный цвет зелёный #2E7D32.

## Правила ведения работы (для Claude)

1. Работать пошагово, ждать подтверждения пользователя после каждого шага.
2. После завершения каждой вехи — предложить пользователю обновить этот файл (Claude готовит новую версию, пользователь коммитит: Commit → Sync).
3. **Правило трёх вех:** после закрытия каждых трёх вех в текущем чате Claude сам: (а) напоминает пользователю, что пора открыть новый чат, (б) готовит обновлённый CLAUDE.md, (в) выдаёт готовый стартовый текст для нового чата. Также предлагает смену чата раньше, если разговор стал очень длинным.
4. Claude всегда даёт готовые файлы для вставки (не просит пользователя писать код руками).
5. **Именование одиночных файлов:** имя файла = путь в проекте, разделитель папок — двойное подчёркивание `__`. Пример: `app/(tabs)/index.tsx` передаётся как `app__(tabs)__index.tsx`. Пользователь кладёт файл по указанному пути и переименовывает в последнюю часть имени (`index.tsx`). Claude в инструкции всегда дублирует: куда положить и как переименовать.
6. Если файлов больше двух — передавать архивом (.zip) с готовой структурой папок: распаковать в корень проекта с заменой.
7. Перед крупными изменениями проверять код компилятором (tsc) на своей стороне.

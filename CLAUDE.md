## Что это за проект

**Минги-Тау** — закрытое мобильное/веб-приложение (сообщество) для карачаевцев
и балкарцев по всему миру. Вход только по приглашению. Подпись бренда:
«Карачаево-Балкарское сообщество».

Владелец проекта — Мурат, не программист. Правила работы с ним:

- Строго пошагово, одно действие за раз, без жаргона.
- Окружение: Windows, PowerShell, VS Code, папка проекта `C:\dev\Diaspora`.
- Отправка на GitHub: Source Control → Commit → Sync Changes.
- Всегда давать готовые файлы (не просить писать код руками).
- Одиночные файлы называть по пути с `__` вместо `/`
  (пример: `app__(tabs)__index.tsx`), всегда писать куда положить и как
  переименовать. Больше двух файлов — zip-архив со структурой папок.
- После каждой вехи обновлять CLAUDE.md. После трёх вех в одном чате —
  напомнить открыть новый чат и подготовить стартовый текст.
- Второстепенные пожелания записывать в раздел «Отложенные задачи».

## ПОДТВЕРЖДЕНИЕ ПОЧТЫ (Веха 8) — собственная система, переносимая

Почта подтверждается **своим** 6-значным кодом, а не встроенным механизмом
Supabase. Сделано так специально: при переезде на Яндекс переедет целиком.

- Ящик проекта: `mingi-tau-id@yandex.ru`, отправка по SMTP
  (`smtp.yandex.ru:465`, пароль приложения типа «Почта», в настройках ящика
  включён доступ по IMAP/SMTP).
- Секреты Supabase: `YANDEX_SMTP_USER` (полный адрес), `YANDEX_SMTP_PASS`
  (пароль приложения без пробелов). После смены секретов функцию нужно
  задеплоить заново.
- Таблица `public.email_verification_codes` (email, code, created_at,
  expires_at, attempts, verified). RLS включён — доступ только у функции.
- Edge Function `send-email-code` (действия `send` и `verify`):
  код живёт 10 минут, пауза между отправками 60 сек, максимум 5 попыток
  ввода, старые коды удаляются при новой отправке.
- **ВАЖНО про письмо:** тема и имя отправителя — ТОЛЬКО ЛАТИНИЦА
  (`Mingi-Tau: code 123456`). Кириллица в заголовке даёт крякозябры, а
  ручное кодирование RFC 2047 приводит к двойному кодированию — не делать.
  Русский текст живёт внутри письма (html + content) — там всё в порядке.
  HTML-письмо оформлено в фирменном стиле (мятный фон, код в рамке).
- Поток регистрации: шаг 1 контакты → отправка кода → шаг 2 ввод кода
  («Изменить почту» возвращает на шаг 1 с сохранением полей, повторная
  отправка с таймером) → шаг 3 анкета. Инвайт тратится только при финальной
  отправке. Заявки с несуществующей почтой до модератора не доходят.
- Решено: **телефон НЕ подтверждаем** (SMS платные; защита обеспечена
  инвайтом и модерацией).

## ДИЗАЙН-СИСТЕМА (утверждена, основополагающая для ВСЕХ экранов)

Стиль: светлый, воздушный, пастельный «iOS / liquid glass». Отсылки к
культуре: логотип-гора и знак **текмет** (круг + ромб + точка).

**Живой фон с боке — только на welcome, splash и pending-approval.**
Экраны с формами и рабочие экраны — на белом `#FFFFFF`.

**Иконки:** текмет во всю ширину на прозрачном фоне, зелёный `#69B78D`.
Исключения: apple-touch-icon и maskable — на белой подложке; Android —
знак в безопасной зоне. Файлы: `assets/images/`, `public/icons/`.

### Общие файлы

`components/mingi.tsx` — Glass (слои с `pointerEvents="none"`, контент
через zIndex), Blob, useDrift, Tekmet, MingiBackground (уникальный
`idPrefix`). Побочный эффект при импорте: глобально отключает чёрную
браузерную рамку фокуса в вебе.

`components/AvatarCrop.tsx` — окно кадрирования фото: перетаскивание,
масштаб − / +, круг, обрезка 512×512 JPEG. Экспортирует
`prepareAvatarSource()` — сразу уменьшает фото (≤ 1600 px).

### Палитра

- Фон живых экранов: `#F4FAF4`; фон форм: `#FFFFFF`
- Заголовки: `#3F6B5B`; вторичный текст (капс, letterSpacing 2.5): `#719686`
- Текст на стекле / подсказки списков: `#4E7364`
- Кнопка primary: `rgba(105,183,141,0.92)`, текст `#FFFFFF`, тень `#69B78D`
- Кнопка secondary: белая/стекло, абрис, текст `#3F6B5B`
- Поля: `rgba(255,255,255,0.95)`, радиус 16, абрис `rgba(93,140,120,0.45)`
  0.75, плейсхолдер `#8FA79A`, текст `#2F4A3C`
- Служебный текст: `#7E988B`, ссылки: `#96AC9E`; ошибки/опасное: `#C05B4D`
- Боке: `#A8D8C0`, `#C2E3CF`, `#DFEFE3`, `#B7DEC8`, `#CDE8D6`

### Шрифты

**Philosopher** (OFL): `Philosopher_700Bold` — заголовки,
`Philosopher_400Regular` — подписи. `useFonts` внутри экрана, до загрузки —
пустой фон. Системный шрифт — кнопки и служебный текст (fontWeight 600).

### Шаблон экрана с формой

Заголовок Philosopher 34 → подпись капсом → текмет → поля → primary-кнопка
→ ссылки. Радиусы: кнопки 18, поля 16. Обязательные поля — `*` в
плейсхолдере + строка «Поля со звёздочкой (\*) обязательны»; кнопки
неактивны (opacity 0.7), пока обязательные поля не заполнены. Поля с
выбором из списка (сфера деятельности) — ввод с подсказками + проверка
совпадения со списком.

### Веб и PWA

`app/+html.tsx` — заголовок «Минги-Тау», theme-color, манифест, мета-теги
для iPhone. `public/manifest.json` — манифест PWA. Кнопка установки
появится после публикации на https.

Переведены на дизайн-систему:

- `welcome` (живой фон; Glass там ещё локальный старый — косметика)
- `splash` (живой фон, логотип, текмет, 3 секунды)
- `login`, `invite`, `request-invite` (белый фон)
- `register` (три шага: контакты → код → анкета; кроп аватара; умная сфера)

  при одобрении сам уводит на splash без повторного входа)
- `contact-admin`, `edit-profile`, `change-email`, `change-password`
  (белый фон; edit-profile с кропом и умной сферой)

Ещё в старом стиле: `(tabs)/*`, `chat`, `profile`, `user-profile`,
`moderation`, `moderation-*`, `invites`, `request-name-change`,
`access-restricted`, `profile-deleted`, `report-user`, `privacy`, `terms`.

Прочее:

- `services/sessionService.ts` — `.maybeSingle()` вместо `.single()`.
- `services/moderationService.ts` — approveUser/rejectUser проверяют, что
  база приняла изменение, иначе честная ошибка (раньше «тихий успех»).
- `app/moderation.tsx` — новые заявки сверху во всех вкладках.

## Функциональность (работает, проверено сквозной проверкой)

Инвайт → регистрация с фото и подтверждением почты → модерация →
одобрение → каталог с аватаром. Также: профили, поиск, избранное, жалобы,
экраны модерации, роли (owner/модератор), блокировки, политика/соглашение.
